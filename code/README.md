Analysis and curation code related to the analysis conducted for this project.

The scripts are composed of three parts: 
- (a) Data cleaning and cohort construction - developed and implemented in NHS England SDE
  - Coded in `PySpark`
- (b) Data analysis - developed and implemented in NHS England SDE
  - Coded in `R`
- (c) Figure making
  - Coded in `R`
 
See README files in the individual folders above for detailed description of scripts.
