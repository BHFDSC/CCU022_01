## Data analysis

Scripts in this folder were developed and implemented in the [NHS England SDE](https://digital.nhs.uk/services/secure-data-environment-service). Briefly, we trained and tested Comorbidity Risk Scores (CRSs), performed cross-ethnicity evaluations of CRSs, and evaluated the performance of other competing models.

See README files in `Index2015` and `Index2020` folders for detailed description of the scripts.
